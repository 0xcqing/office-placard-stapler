Writes a single museum placard for an office stapler, recovered from the Tomb of the Eternal TPS Report, to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The program writes one line of at most 180 characters to `entry.txt`.
